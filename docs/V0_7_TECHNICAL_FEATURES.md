# V0.7B — Deterministic Technical Features

## Objective

Indicators are reproducible Python calculations, not numbers generated by an LLM.
`build_technical_feature_snapshot(dataset)` consumes one validated V0.7A dataset and
returns immutable calculated metrics. It performs no IO, market retrieval, persistence,
calendar lookup or interpretation.

## Inputs

`HistoricalOHLCV` from V0.7A: chronological, validated RAW completed daily bars with
explicit as-of, provider vintage, calendar provenance and missing-session metadata.
Bar/model invariants are defensively revalidated; V0.7A remains responsible for calendar
and completed-bar construction. The builder does not silently repair manually forged
or otherwise invalid inputs.

## Feature Set

| Feature | Parameters / units | Minimum completed observations |
| --- | --- | --- |
| SMA | 20, 50, 200; price | N |
| Close distance to each SMA | (close / SMA − 1) × 100; percent | N |
| Trend structure | strict close/SMA20/SMA50/SMA200 ordering | 200 |
| RSI | Wilder 14; 0–100 | 15 |
| MACD line | EMA12 − EMA26; price | 26 |
| MACD signal / histogram | EMA9 of MACD / line − signal; price | 34 |
| ATR / ATR percentage | Wilder 14; price / percent | 15 |
| Momentum | 5 and 20 session close returns; decimals | N + 1 |
| Average volume / volume ratio | 20 observations; shares / dimensionless | 20 |

Optional realized volatility is deliberately omitted. ATR supplies the initial
volatility measure. No additional indicator families or support/resistance interface
are introduced.

## Methodology

**SMA:** arithmetic mean of the latest N closes. SMA distance is a signed percentage:
5 means 5%, while momentum 0.05 means 5%; each feature carries its unit.

**RSI(14):** form close differences starting with the second bar. Seed average gain
and average loss from the first 14 differences (15 closes). Subsequently smooth each
with previous average × 13/14 + latest gain/loss ÷ 14 through the full supplied dataset.
RSI is 100 × average gain / (average gain + average loss). All gains yield 100, all
losses yield 0, and both averages zero yields the explicit neutral convention 50.
No zero denominator produces NaN.

**MACD(12,26,9):** each price EMA is seeded with the arithmetic mean of its first N
closes, then updated with alpha = 2/(N+1). First EMA12 exists at observation 12 and
EMA26 at 26. MACD lines align from observation 26 onward. Signal EMA is seeded with
the first nine available MACD values at observation 34 and uses alpha 2/10 thereafter.
Line may be available before signal/histogram. Full supplied history affects recursive
initialization: different source start dates may produce different values even with
an identical recent tail. Initialization is not delegated to a library default.

**ATR(14):** starting with the second bar, true range is the maximum of high−low,
absolute high−previous close, and absolute low−previous close. Seed ATR from the first
14 true ranges, then use Wilder 13/14 + 1/14 smoothing. The first bar is not assigned
an invented previous close. ATR percentage = ATR / latest close × 100. Flat bars can
legitimately produce zero ATR.

**Momentum:** latest close / close N observations earlier − 1. It requires N+1 closes,
uses no forecast or annualization, and carries `decimal_return` units.

**Volume:** average of the latest 20 completed volumes, including the latest. Ratio is
latest volume / that average. Zero latest volume can yield zero ratio; all-zero volume
makes the ratio unavailable while average volume remains a valid zero. This is not an
accumulation/distribution or institutional-activity classification.

**Trend structure:** `BULLISH_STACK` means close > SMA20 > SMA50 > SMA200;
`BEARISH_STACK` means the strict reverse. Equality or any other complete ordering is
`MIXED`. Missing prerequisites make the feature unavailable. These names describe
ordering only, not recommendations, technical signals or confidence.

## Missing History

Each frozen `FeatureValue` carries name, value, unit and optional unavailable reason.
A non-None value is available; None always has a reason. Missing history produces
`UNAVAILABLE_DUE_TO_HISTORY`; gaps produce `UNAVAILABLE_DUE_TO_MISSING_SESSIONS`.
A zero average-volume denominator produces `UNAVAILABLE_ZERO_DENOMINATOR`.

The existing V0.7A sufficiency helper checks trailing windows. SMA, volume and momentum
use only their required window. RSI, ATR and MACD consume all supplied history, so a
gap anywhere in that recursive history makes them unavailable; they do not silently
reseed after a gap. A 50-bar snapshot retains shorter features while SMA200 is missing.
An empty dataset yields a valid all-unavailable snapshot. Unexpected arithmetic or
programming errors propagate; they are not disguised as missing history. Non-finite
numeric outputs are rejected, not replaced with zero.

## Point-in-Time Integrity

Features consume only the input dataset. No current quotes, provider JSON or future
bars are inputs. V0.7A filters unfinished bars; a test changes a provider's eventual
Monday close while the requested as-of is Monday 10:17 and verifies identical features.
No normalized bars or V0.6 historical records are mutated.

## Provenance

`TechnicalFeatureSnapshot` retains the immutable source dataset itself, preserving
symbol, as-of, last session, first session, normalization version, retrieval vintage,
RAW mode, calendar and availability limitations without reconstructing provenance.
It exposes symbol/as-of/latest-session/latest-close properties, a tuple of feature
values and explicit parameter tuples. The feature methodology is
`technical-features-v1`. Parameter/initialization changes require deliberate versioning.

## Data Integrity

- **RETRIEVED FACT:** V0.7A provider OHLCV under its stated vintage.
- **CALCULATED METRIC:** all features, distances and ordering categories here.
- **AI INTERPRETATION:** none. There are no prompts or OpenAI calls.

Eight focused tests were added; the complete offline suite now contains 367 passing
tests. Coverage includes independently known RSI values, analytic MACD ramp/impulse
cases, ATR normal/gap cases, SMA/momentum indexing, zero volume, missing-history/gap
behavior, immutability, provenance and future-bar exclusion. No live APIs were called.

## Limitations

RAW splits/dividend discontinuities can distort features; no corporate-action correction
is inferred. Historical provider publication/revision uncertainty from V0.7A remains.
These are descriptive calculations, not proof of predictive usefulness. No support/
resistance, regime detection, technical recommendation, confidence, LLM Technical
Analyst, chart interpretation, trading, persistence or dashboard changes are included.
V0.6 provider-adjusted evaluation remains unchanged and separate.
